## Significant Architectural Changes

- Two-DB-backend abstraction (`db_backend.py`) introduced for SQLite ↔
  Postgres portability (07-18)
- Change ledger (`changes.py`) with full revert, no silent overwrites (07-17)
- Line-manager approval flow with Entra/Keycloak dependency gate (07-30) —
  see `architecture-decisions.md`
- Budget alerts redesigned as forecast-gated rather than raw-threshold (07-26)
- AI output correctness/safety: English-only guarantee across all AI
  modules, leaked-reasoning stripping in netdiag + notifications (07-22, 07-26)

## Lessons Learned

- Raw-SQL tables living outside `models.py` (subinventory, budget_alert_state,
  agent_chats) repeatedly needed separate Postgres-compatibility fixes
  (PRAGMA no-ops, migration script coverage) — this is now a known pattern
  to check proactively for any *new* raw-SQL table (see `known-issues.md`).
- AI-drafted content (notifications, netdiag summaries) needed multiple
  passes to guarantee English-only output and reject leaked chain-of-thought
  — template-first-with-AI-enhancement (never AI-first) is the pattern that
  stuck.
- Cost/optimizer features needed several follow-up perf fixes (queries
  blocking pages, auto-discovering readable management group) — live Azure
  Cost Management queries are slow/fragile enough to need decoupling from
  page render paths.
