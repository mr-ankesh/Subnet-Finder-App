3. First-time setup — log in at /admin/login and open Settings:
     • Azure Credentials  → service principal / managed identity + Test Connection
     • Hub, Firewall, Routing → your hub topology
     • AI Agent / LLM     → provider, model, API key (stored encrypted)
     • Safety             → keep DRY-RUN ON until everything is verified

   Settings changes apply live (DB override → env → default). The values in
   this chart's ConfigMap/Secret are only bootstrap defaults.
